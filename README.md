# Competition **#1: ZKsync OS - Cryptography**

Welcome to another Security Competition by [Taran.Space](https://www.taran.space).

Our mission is simple yet ambitious — to uncover and prevent as many security issues as possible in high-stakes open-source projects, including:
- Exploits and vulnerabilities
- Design flaws
- Backdoors
- Weak spots and unsafe practices
- Denial-of-Service (DoS) potentials

This time, we’ll be auditing **[ZKsync OS](https://docs.zksync.io/zk-stack/components/zksync-os)**.
